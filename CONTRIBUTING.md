# Mitwirken

Danke für dein Interesse! Kurzfassung:

1. Issue anlegen oder bestehendes kommentieren (bei größeren Änderungen bitte vorher abstimmen).
2. Branch von `main`, Änderungen mit Tests, `pnpm check` und ggf. `pnpm test:e2e` lokal grün.
3. Commit-Nachrichten nach [Conventional Commits](https://www.conventionalcommits.org/de/).
4. Pull Request öffnen – die CI baut Installer für alle Plattformen zum Testen.

**Fehlerhafte Anzeige einer Rechnung?** Bitte – wenn möglich anonymisiert – die XML/PDF
anhängen oder die betroffenen Elemente beschreiben. Jeder behobene Fall wird als Fixture in
die Testsuite aufgenommen.

Technische Details und Konventionen: [AGENTS.md](AGENTS.md), [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
